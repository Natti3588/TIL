## errors.Asの概要と使い方

### 概要

`errors.As`は特定の方に一致するエラーを見つけ出し、そのエラー値を取り出すために使われる。

`errors.Is`が特定のエラー値と一致するかを調べるのに対し、`errors.As`は特定の方に一致するかを調べる問う違いがある。

### 使い方

```go
package main

import (
	"errors"
	"fmt"
)

// カスタムエラー型を定義
type NotFoundError struct {
	Name string
}

func (e *NotFoundError) Error() string {
	return fmt.Sprintf("%s not found", e.Name)
}

func findUser(name string) error {
	// ここでラップして返す
	return fmt.Errorf("failed to find user: %w", &NotFoundError{Name: name})
}

func main() {
	err := findUser("alice")

	var notFoundErr *NotFoundError
	if errors.As(err, &notFoundErr) {
		// 型が一致したので、フィールドにアクセスできる
		fmt.Println("見つからなかったユーザー:", notFoundErr.Name)
	} else {
		fmt.Println("別の種類のエラーです:", err)
	}
}
```
出力:
```
見つからなかったユーザー: alice
```
