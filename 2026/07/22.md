## Goでのテストの書き方

Goのテストは標準パッケージの`testing`だけでほぼ完結する。

### 基本形

ファイルは`_test.go`で終わらせて、テスト対象と同じディレクトリに置く。

```go
// calc.go
package calc

func Add(a, b int) int { return a + b }
```

```go
// calc_test.go
package calc

import "testing"

func TestAdd(t *testing.T) {
	got := Add(1, 2)
	if got != 3 {
		t.Errorf("Add(1, 2) = %d, want 3", got)
	}
}
```
関数は`Test`で始まり、続く文字が太文字。 引数は`*testing.T`

### テーブル駆動テスト

Goで最も一般的なテストの手法。 ケースをスライスでもち、`t.Run`でサブテストをする。

```go
func TestDivide(t *testing.T) {
	tests := []struct {
		name    string
		a, b    int
		want    int
		wantErr bool
	}{
		{"正常", 6, 3, 2, false},
		{"割り切れない", 7, 2, 3, false},
		{"ゼロ除算", 1, 0, 0, true},
	}

	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			got, err := Divide(tt.a, tt.b)
			if (err != nil) != tt.wantErr {
				t.Fatalf("err = %v, wantErr %v", err, tt.wantErr)
			}
			if got != tt.want {
				t.Errorf("got %d, want %d", got, tt.want)
			}
		})
	}
}
```
