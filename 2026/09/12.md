## 学んだこと

Go言語の`Context`インターフェースのドキュメントを読んだ

## わかったこと

`Context`インターフェースは以下のメソッドを定義している。

`Deadline`はこのContextに関する処理をキャンセルすべき時刻を返す。

```go
Deadline() (deadline time.Time, ok bool)
```

`Done`はこのContextに関する処理をキャンセルすべき時にcloseされるchannelを返す。

```go
Done() <- chan struct{}
```

`Done`がcloseされていない場合、`Err`はnilを返す。
Doneがcloseされている場合、Contextが終了を示すエラーを返す。

```go
Err() error
```

`Value`は、このContext内でkeyに関連付けられている値を返す。
対応する値が存在しない場合はnilを返す。

```go
Value(key any) any
```
