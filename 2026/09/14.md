HTTPSの仕組みについての深堀

## わかったこと

まず大前提として`HTTPS`は`HTTP`を`TLS`という仕組みで保護した通信のこと。

HTTPだけの場合だと
```
Client ───── HTTP ─────> Server
       ID: taro
       Password: abc123
```
のように、通信経路上のデータが平文なので、途中で盗み見られてしまう危険がある。

HTTPSでは
```
Client
   │
   │ TLSで暗号化
   ▼
Internet
   │
   │ 暗号化されたデータ
   ▼
Server
```
となり、暗号化・認証・改ざん検知を実現しています。

### HTTPS接続の全体像

ブラウザから`https://example.com`へアクセスすると、**TCP接続**をまずはやります。
HTTPのデータをTLSで暗号化してTCPで送信します。
その次に**TLSハンドシェイク**を行います。
目的は「相手のサーバーは本物なのか確認する」ことと「これから通信を暗号化するためのカギを安全に決めること」です。
その次にクライアントからサーバーへ**ClientHello**を行い、サーバーにTLSバージョンや暗号化アルゴリズムを伝える。
