## NAT と iptables の仕組み

まず、iptables とは LinuxカーネルのNetfilter を操作するためのコマンドラインです。
これによって、通信を許可・遮断したり、パケットのIPアドレスやポート番号を書き換えることができるようになります。

送信元のIPを書き換える方法は`SNAT`と`MASQUERADE`の二つがあります。
`SNAT`は主な用途としては IP が固定の環境で使われるのを推奨されていて、変換後の IPアドレスを明示的に設定する必要があります。
以下が `SNAT` をする際のコマンドです。
```Bash
iptables -t nat POSTROUTING -o eth0 -j SNAT --to-source 10.0.1.10
```

続いて、`MASQUERADE`は`SNAT`とは逆で IPが動的に変わる環境に使用されます。
`SNAT`ととは違い、変換後の IPアドレスを明示する必要はありません。
自動的に`-o`で指定した IPを使います。
以下が `MASQUERADE`をする際のコマンドです。
```Bash
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
```

そして送信元IPアドレスはNATインスタンスに付与されているパブリックIPに変換されるのではなく、NATインスタンスのプライベートIPに変換されてから、IGWでパブリックIPに変換されます。
