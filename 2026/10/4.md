# 今日学んだこと

- iptables

## わかったこと

**iptables**とはLinuxカーネルの Netfilter を操作し、ネットワークの通信制御やアドレス変換（NAT）を行うコマンドラインのファイアウォールユーティリティ。

### 基本構造と仕組み

**テーブル**
	機能ごとの分類。
	パケットフィルタリングを行う filter アドレス変換を行う nat がある。

**チェイン**
	パケットの流れる方向ごとのグループ。
	入力を処理する INPUT 出力を処理する OUTPUT 転送を処理する FORWARDがある。

**ターゲット**
	ルールに一致したパケットの処置。
	許可する ACCEPT
	破棄する DROP
	拒否する REJECT などがある。
