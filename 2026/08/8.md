## TypeScriptのtypeとinterfaceの違い

### 表現できる範囲
`type`のほうが広く、ユニオン型やタプルなどが扱える。
`interface`はオブジェクトの形に限られる。

### 宣言のマージ
`interface`は同名で複数宣言すると自動的に結合されます。
`type`は再宣言するとエラーを出す

```ts
interface Window { myApp: string; }
interface Window { version: number; }  // → 両方持つ Window になる

type A = { x: number };
type A = { y: number };  // Error: Duplicate identifier

```
