# 2026-08-26

## 学んだこと

Terraformのデータソースから使えるアベイラビリティゾーンを取得する方法

## わかったこと

今日はTerraformの`data`を使って使えるアベイラビリティゾーンを取得して、サブネットを作成してみました。

やり方は
`data`を使って外部のAPIからインフラ情報を取得する。
今回の場合は使用できるアベイラビリティゾーン

```tf
data "aws_availability_zones" "available" {
  state = "available"
}
```
これで、自分のAWS環境から使用できるアベイラビリティゾーンを取得できます。

そして、`local`で使用するアベイラビリティゾーンの数を調整して、`for`で`map`にします。

```tf
locals {
  azs = slice(data.aws_availability_zones.available.names, 0, var.az_count)

  public_subnets = {
    for idx, az in local.azs : az => {
      az   = az
      cidr = cidrsubnet(var.vpc_cidr, 8, idx)
    }
  }
}
```

最後に`aws_subnet`で先ほど作成したmapを`for_each`で回して、azを一つずつ取得して一つずつサブネットを作成します。
```tf
resource "aws_subnet" "public" {
  for_each = local.public_subnets

  vpc_id            = aws_vpc.main.id
  cidr_block        = each.value.cidr
  availability_zone = each.value.az
}
```

## わかったこと

今日で`data`ブロックという外部のAPIを叩いてインフラの情報を取得する方法を知り、それを使用して
複数のサブネットを作成する方法を知りました。
まだ`for_each`や`slice`などの関数も完全には理解していないので、インフラの構成だけではなく
関数の使い方も勉強したいです。
