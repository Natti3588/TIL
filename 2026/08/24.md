## わかったこと

今日は3日ほど前から読んでいるTerraformの書籍の知識を定着化させるために、AIにインフラを構築するよう
問題を出題させました。
まだ初日ということもあり全体的に見ることはできませんが、AIに答えを聞くことをやめて公式のリファレンスや書籍からコードの書き方やディレクトリの配置などを学んでいるので、AI任せのコーディングより格段に知識の定着化につながっていると感じます。

とりあえず今日学んだことは**resource / variable / output / terraform / provider**ブロックをそれぞれ駆使して
Dockerのコンテナを作成することです。
それぞれの意味は

**resource** -> インフラを定義する重要なブロック
**variable** -> 名前の通り変数のブロック。 ハードコードを避けるために使う
**output** -> `terraform apply`でデプロイした後にCLIに出すメッセージを定義
**terraform** -> Terraform自体に必要なバージョンを指定
**provider** -> Terraformと外部のクラウドサービスを接続するプラグインを設定する
